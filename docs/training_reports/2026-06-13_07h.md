## MÓDULO 3 — Security Reinforcement

### OWASP LLM Top 10 — Reinforcement (sessão 07h Jun 13)

**LLM01 — Prompt Injection:**
- Presente em 73% de deployments de produção de AI (2026)
- Defesa crítica: separação de system instructions vs user input — "prompt injection works because system, developer, and user inputs are all in the same context"
- iCLONE: todos os inputs são dados. Nunca comandos.

**LLM02 — Insecure Output Handling:**
- Outputs validados antes de qualquer submissão. Nunca raw LLM output on-chain.

**LLM07 — Insecure Plugin Design:**
- Least privilege em cada skill. Scope definido. Zero cross-skill data leakage.
