# The university's scientific repository — Doctor's home ground

_Skill artifact for **doctor-agent** (academic rigor (IST)) — last studied 2026-08-25._
_Agent focus: IST-standard papers and dissertations; the university's scientific repository._

## Key points
- Two doors: Técnico Scholar (IST output) and Repositório ULisboa (theses/dissertations, university-wide) — probed live each session.
- The metadata record is the citable object; follow handles/DOIs, never copied PDF links.
- Check access level before promising a source; cite the deposited version of record for theses.
- Repository-first verification: unresolvable references never enter a manuscript.

## Worked drills
- ✅ **no-fabrication** — A cited paper cannot be found in any repository.
  - Resolution: Fabricated or wrong — either way it leaves the manuscript. Every reference must resolve (DOI, handle, or repository record) before submission. Never invent a source.
